# Lipid Profile Analysis — Portfolio Project

Cross-sectional analysis of lipid profile patterns across BMI categories
in medical students using Asian WHO cutoffs.

## Skills Demonstrated
R · ggplot2 · one-way ANOVA · chi-square · Pearson correlation ·
Quarto · academic reporting · effect sizes (η²) · survey data analysis

## Methods
- 203 simulated medical students, 3 BMI groups (Asian WHO cutoffs)
- Descriptive statistics, chi-square, ANOVA with η², correlation matrix
- Publication-ready tables and figures rendered in Quarto

## Reproduce
1. Clone repo
2. Open R and run: `renv::restore()` OR install packages manually
3. Run: `quarto render portfolio_report.qmd`
